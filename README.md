# II. Featured Projects

## A. PixelDesktop

A native macOS application for controlling and coordinating a physical Android device as a local compute node.

The project explores a Mac + Android architecture where the Mac provides the primary interface and orchestration while the physical Android device can eventually operate as a specialized compute worker.

**Technologies:** Swift, SwiftUI, macOS, Android, ADB

## B. School AI Assistant

A school-focused AI assistant designed around grounded institutional knowledge and permission-aware access.

The system explores:

- Markdown-based knowledge
- Source-grounded responses
- File citations
- Permission levels
- Protected information boundaries
- Google Workspace integration
- Agent-based workflows

The institution is intentionally kept anonymous in the public repository.

## C. Expense Tracker

A native macOS personal finance application for recording, organizing, and analyzing financial transactions.

The application includes:

- Expense tracking
- Income tracking
- Categories
- Budgets
- Planned expenses
- Financial summaries
- Local persistence
- Monthly reporting

**Technologies:** Swift, SwiftUI, SwiftData, macOS

# V. Development Approach

I prefer learning through actual systems rather than isolated theory.

My general development process is:

```text
Observe
   ↓
Reproduce
   ↓
Gather Evidence
   ↓
Identify the Layer
   ↓
Form a Hypothesis
   ↓
Test
   ↓
Fix
   ↓
Verify
   ↓
Regression Test
   ↓
Document
```

The goal is not simply to make something work, but to understand why it works and how the individual components form a larger system.
